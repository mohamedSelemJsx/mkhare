# مركز فريق المعرض الطبي

تطبيق ويب قابل للتثبيت على الموبايل (PWA) لفريق المعرض الطبي:
جدول الفعاليات، تأكيد الحضور (RSVP)، المهام والديدلاينات، الإعلانات، ولوحة متابعة خاصة بالمساعد التنفيذي.

- **الواجهة:** React + Vite (ملفات ثابتة) → GitHub Pages
- **المشاركة اللحظية:** Supabase (Postgres + Realtime)
- **التواصل يبقى في واتساب** — هذا التطبيق هو *مصدر الحقيقة*، لا قناة دردشة.

---

## 1) شغّله محلياً

```bash
npm install
cp .env.example .env     # واملأ القيم (الخطوة 2)
npm run dev
```

## 2) جهّز Supabase (مجاني)

1. أنشئ مشروعاً على https://supabase.com
2. **SQL Editor → New query** → الصق محتوى `supabase-schema.sql` → **Run**
3. **Project Settings → API**: انسخ `Project URL` و `anon public key`
4. ضعهما في `.env`:
   ```
   VITE_SUPABASE_URL=https://xxxx.supabase.co
   VITE_SUPABASE_ANON_KEY=eyJhbGc...
   VITE_ADMIN_CODE=اختر-كوداً-لك
   ```

> المفتاح `anon` عام بطبيعته — الأمان عبر Row Level Security لا بإخفائه.

## 3) انشره على GitHub Pages

1. ادفع المشروع لمستودع على GitHub (مثلاً باسم `medexpo-hub`).
2. في `vite.config.js` تأكد أن `BASE` يطابق اسم المستودع: `"/medexpo-hub/"`.
   (لو نشرته على `username.github.io` مباشرة، اجعله `"/"`.)
3. **Settings → Pages → Build and deployment → Source: GitHub Actions**.
4. **Settings → Secrets and variables → Actions** أضف الأسرار الثلاثة:
   `VITE_SUPABASE_URL`، `VITE_SUPABASE_ANON_KEY`، `VITE_ADMIN_CODE`.
5. كل `git push` على `main` ينشر تلقائياً عبر `.github/workflows/deploy.yml`.

الرابط سيكون: `https://<username>.github.io/medexpo-hub/`

## 4) شاركه مع الفريق

أرسل الرابط. للتثبيت كتطبيق:
- **أندرويد (Chrome):** القائمة → "تثبيت التطبيق" / "إضافة إلى الشاشة الرئيسية".
- **آيفون (Safari):** زر المشاركة → "إضافة إلى الشاشة الرئيسية".

كل عضو يدخل اسمه ودوره مرة واحدة. أنت تفتح **وضع المتابعة** من الأسفل بكودك.

## ما الذي بُني (v1) وما الذي تُرك عمداً

**مبني:** الجدول والعدّاد · تأكيد الحضور ومن سيحضر · المهام والديدلاينات لكل دور · الإعلانات · لوحة متابعة (إحصائيات، حضور، إسناد مهام).

**مؤجَّل عمداً** (لتشحن بسرعة، أضِفها فقط عند الحاجة الحقيقية):
- مصادقة فعلية (v1 يعتمد اسماً محفوظاً محلياً + كود متابعة يُتحقق على المتصفح — مناسب لفريق موثوق، ليس حماية حقيقية).
- شات (واتساب يكفي) · رفع ملفات · إشعارات Push (تحتاج إعداداً إضافياً، ومحدودة على iOS).

عند تشديد الأمان لاحقاً: فعّل Supabase Auth (Magic Link) واربط سياسات RLS بـ `auth.uid()`.
